# ESP RainMaker Classic setup

Status: **software prepared; account binding, phone control and TLS/MQTT runtime
are NOT TESTED on hardware**.

## Build

Use the official full ESP-IDF 5.5.1 checkout, including Git submodules:

```bat
call D:\RPA\esp-idf-5.5.1\export.bat
build-variant.bat CORE_CLOUD
build-variant.bat FULL
```

If ESP-IDF was downloaded as an incomplete source archive, confirm these
official submodules are populated before building a cloud variant:

- `components\protobuf-c\protobuf-c`
- `components\mqtt\esp-mqtt`

Prefer `git clone --recursive` or `git submodule update --init --recursive` for
ESP-IDF rather than copying source directories manually.

## First hardware run

1. Flash CORE_CLOUD first and open the USB serial monitor.
2. Configure office Wi-Fi in the local Web page.
3. Confirm `RainMaker Classic started node_id=...` appears.
4. Wait for self-claim and `RainMaker MQTT connected`.
5. Log in to the ESP RainMaker phone app or CLI. User-node mapping requires a
   matching request from both the logged-in client and the node; entering only
   a secret in the local Web page cannot bind an account.
6. In the trusted local Web page, enter the user ID and the same one-time
   mapping secret generated by the client, then submit within the mapping
   timeout.
7. Confirm the page shows account mapping complete and the phone app lists the
   three light switches and explicit OFF actions.

Do not forward port 80 or expose the local administration page to the public
Internet. The one-time mapping secret travels over local HTTP in the current
implementation.

## Expected semantics

- Left/center/right accept ON and OFF.
- A light value changes in the app only after fresh Zigbee feedback.
- All Lights and each LG AC entry are explicit OFF triggers, never Toggle.
- An AC result is only `IR sent` or `failed/unknown`.
- Lux/temperature/humidity are valid only when the matching optional sensor is
  compiled, enabled, online and has a valid sample.
- Disabling RainMaker preserves credentials and requires a controlled reboot
  with SDK 1.17.0.
